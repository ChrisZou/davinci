# 封面排版原则

封面是在信息流里被**缩成指甲盖大小**看的。所有规则都围绕一件事：缩小以后还能一眼看懂。
做完一定 render 出来看；看的时候把图想象成手机屏幕上的一小格。

## 结构

一张封面通常只有三样东西，按重要性：

1. **主标题**：一句话说清"这期讲什么"。2 行以内，每行不超过 8 个字，越短越好。
2. **视觉主体**：人像（表情和手势比长相重要）、产品截图或一个大图标。
3. **辅助信息**：副标题 / 标签条（"10 款实测""一周省 20 小时"）、署名。可以没有。

多于这三样就是在稀释注意力。

## 尺寸与位置（小红书 3:4，1242×1656，其他比例按比例换算）

- 页边距：左右 72–96，上下 96 以上。重要内容别贴边——平台会在角上压按钮和角标。
- 主标题字号 140–180，字重 800–900，行高 1.0–1.1。副标题 56–72。
- 人像通常贴底放（`y + height = 1656`），占画面高度 55%–70%，头部不要被标题压住。
- 标题和人像**分区**：人在右下，标题就在左上；人在正中偏下，标题就在上方通栏。

## 用好人像的标注

`davinci lib show <id> --json` 里的 `meta`：

- `placement.best_subject_regions`：人物该放在画面哪里（如 `right`、`lower_right`）。
- `placement.copy_or_object_regions`：标题 / 产品卡该放哪（通常是手指或视线指向的方向）。
- `p_strategy.keep` / `avoid`：哪些不能裁、哪里不能压字（比如"不要让长标题压住指尖"）。
- `gesture_target`：手势指向。指向左上的人像放右侧，标题放左上，让手指把视线引到标题上。
- `use_cases`：这张适合的题材，选图时对照主题挑。

说明文字 `description` 里的【适合怎么P】是同一套信息的人话版本，也要读。

## 颜色与可读性

- 字和背景要有明显明暗差：深底白字、浅底黑字。背景花的时候给字加底色（`yellow-box`、
  `red-box`）或粗描边（`outline-black`，记得 `paintFirst: true`）。
- 整张图 2–3 个颜色就够：一个主色、一个强调色（标签条 / 重点词）、黑白。
- 人像衣服颜色和背景别撞色；撞了就换背景色或加一个色块垫在人后面。

## 常用版式（坐标以 1242×1656 为例）

**左上标题 + 右下人像**（手势指向左上时最自然）
- 人像：高约 1000–1100，贴底，`x` 让人偏右（右边可以出画一点）。
- 主标题：`x 72, y 150`，`width 760`，2 行。
- 副标题 / 标签条：主标题下方 40–60 像素。

**上方通栏标题 + 中下人像**（正面、双手展示类）
- 主标题：`x 72, y 120`，`width 1098`，`textAlign center` 或左对齐。
- 人像：居中贴底，高约 950。

**顶部色块 + 标题 / 下方人像**（背景是纯色时加层次）
- 色块：`addShape rect 0,0,1242,600`，深色；标题白字压在色块上。
- 人像贴底，头部可以和色块边缘交叠一点，更有纵深。

## 自查清单（render 后逐条看）

- [ ] 缩到很小还能读出主标题吗？
- [ ] 字有没有压到人脸、手指？
- [ ] 有没有元素贴边或出界（不是有意出血）？
- [ ] 标题只有一个视觉焦点吗？副标题是不是明显更小？
- [ ] 颜色超过 3 个了吗？
